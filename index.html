Rules I work by

A lock you never test is just jewelry.

A security control nobody has tried to break is only a guess. Test it before someone else does.

Every input is a stranger. Check its ID before it comes in.

Forms, URLs and API calls can all carry attacks. Validate everything on the server, every time.

Most attackers don’t break in. They log in.

Stolen and reused passwords are one of the most common ways in. MFA and a password manager close that door.

A secret in the repo is a gift to strangers.

Keys and passwords committed to code get found, often fast. Keep them in a vault, not in Git.

The test you skip is the bug someone else finds.

Better that it’s your pipeline that finds it, on a Tuesday, than an attacker on a Friday night.

Security isn’t a feature you ship. It’s a habit you keep.

One scan before launch isn’t enough. New code brings new holes, so the checks have to run on every change.
